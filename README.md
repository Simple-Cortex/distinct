# Distinct

An evidence-led brand identity skill for coding agents.

**Status: in development. There is no release yet, so there is nothing to install.**

When the first release ships, this repository will contain the installable skill and the source for its `distinct-rs` companion binary. Installing it will look like this:

```sh
npx skills@latest add Simple-Cortex/distinct
```

Until then, that command has nothing to install.
